# 更新记录

根据现有发行说明整理；当前版本 0.8.6。

## 0.8.6

- 修复恢复／复制会话时，运行记录 ID 与桌面会话 ID 不一致导致的名称缺失、错误跳转和 token 速度不可用。
- 通过数据库中的会话文件路径元数据关联当前 ID，不读取会话文件内容。
- 关联后按最新会话状态去重，避免旧运行记录在会话结束后继续显示。
- 新增恢复会话、结束状态、重复记录和文件名边界的回归测试。

## 0.8.5

修复主题来源。悬浮圆、详情窗和调试窗跟随 Codex 设置中的浅色、深色或跟随系统；读取 desktop.appearanceTheme，约每 0.5 秒检查本地设置变化。主题同步独立于额度轮询，配置暂时不可读时保持上一次外观。切换主题不重置沙量、调试参数或落沙。验证：test_appearance.py、appearance.cjs、native-appearance.py。

## 0.8.4

调试模式新增「细砂 · 灰度纹理与流量」（fine）。只使用灰度亮度，细颗粒在直线中心密实、边缘逐渐稀疏；上端连接上半部沙子，外壁保持原有高光。流量 0 暂停，0.01–0.12 逐粒落下，0.25 细流，1 凝实，2–4 更粗；下落速度恒定，流量改变粗细和密度。透光程度 0–2 调整粒子的灰度亮度，没有单独闪烁或彩色高光。仅调试时生效，关闭后恢复原有自动落沙。验证：fine-sand.cjs、native-debug.py。

## 0.8.3

实际窗口记录显示悬停状态和 brightness(1.4) 一直维持，但用户仍观察到先亮后暗。因此移除悬浮圆的 brightness 滤镜，以中性背景与前景颜色的渐变实现明暗呼应，绕开滤镜的显示合成路径。保留 2% 缩放、760/850 ms 时长、原有沙量对比和详情动画；没有应用背光或呼吸预览方案。验证：hover-stability.cjs、hover-response.cjs。

## 0.8.2

修复悬停先变亮再变暗。指针仍在悬浮圆内时，圆的缩放和明暗呼应保持；收起详情不能提前取消实际悬停效果。原有 2% 缩放、1.4 倍明暗变化、详情浮现与落沙方案保留。验证：`node tests/hover-stability.cjs`。

## 0.8.1

调试窗增加「闪耀方案」选择器，可切换原有柔光、晶点、星芒、流光、彩砂。新方案同时改变亮点面积、形状及持续时间，强度滑杆也改变亮点大小，使 44 px 圆内更易辨识。晶点有较大彩色亮点和白色核心；星芒有四角光线；流光有短尾迹；彩砂保持可见颜色。所有方案仅调试期间生效，关闭调试仍恢复原有自动流速与柔光。`quota_update_settings` 增加 `sandSparkleStyle`：soft / crystal / star / trail / color；值保存于 `debug.json` 的 style。验证：`node tests/sparkle-styles.cjs`。

## 0.8.0

右键悬浮圆 →「调试落沙…」打开原生调试窗。流速 0–4 倍（0 暂停），闪耀程度 0–2 倍（0 关闭反光），两个滑杆立即作用于悬浮圆。调试允许无会话时演示落沙，不改变真实额度、沙量、会话列表或模型系数；减少动态效果、隐藏与额度翻转仍会暂停粒子。关闭调试窗或取消勾选后恢复自动落沙，普通退出也关闭调试。参数保存在独立的 `debug.json`，下次打开调试窗保留，恢复默认将两项都设为 1。

## 0.7.2

悬浮圆改用轻微缩放与明暗变化组合，约 760 毫秒舒展至 1.02 倍并提亮，约 850 毫秒柔和恢复。浅色与深色均保持中性色调，移入详情时保持呼应。详情的浮现、关闭、定位和悬停宽限不变；减少动态效果时仅保留静态提亮。额度沙量、圆环轨道、拖动区域及显示范围保持原样。

## 0.7.1

悬停时圆环视觉舒展 2.5%，背景与沙漏轻柔泛起暖光，约 360 毫秒进入、520 毫秒收回。圆的实际尺寸、触发区域和额度沙量保持不变。移入详情时继续呼应，离开后随原有悬停宽限平滑恢复；减少动态效果时保留静态暖色反馈。`node tests/hover-response.cjs` 验证进入、离开、详情转移及减少动态效果。

## 0.7.0

落沙掺入淡金、青蓝、粉紫等细微反光，随砂粒淡入淡出。仅运行会话且数据新鲜时出现；暂停、翻转、隐藏和减少动态效果时停止。新增 `quota_read_api_prices` 与 `quota_apply_api_prices`，用于周期核对官方价格后更新系数。更新保留默认系数、手动改变的模型系数和已清除的覆盖，只更新与上次价格推导值相符的模型及新定价模型。价格快照保存在 Application Support 的 `prices.json`；只接受同币种、原有混合口径及模型对应的官方域名。每周核对任务由 Codex 自动化运行，不改变日常额度读取的 30 秒周期。

## 0.6.1

按已核对的 API 价格统一计算并赋值。以 GPT-6.1 Sol 为 1 倍，使用 Standard 短上下文、未缓存输入与输出各占 50% 的固定口径：系数 = (输入单价 + 输出单价) / 12。价格单位为美元 / 百万 token。由于本机只提供累计总 token，输入 / 输出 / 缓存比例不可区分，这只是用于落沙的价格权重，不等于订阅额度扣费倍率。

## 0.6.0

落沙速度改为本机运行中会话的 token 增量速度 × 模型系数；默认所有模型 1 倍。每 2 秒只读累计 token 和模型元数据，取近期 30 秒的加权平均，约用 2 秒平滑过渡。计数分批更新时，按前后计数的实际间隔分摊，避免误认为两秒内瞬间消耗；首次看到的历史总数只用来建立基线。会话退出、模型变化、计数回退、账户切换、数据缺失或系数调整后重新建立基线。没有新 token 数据时，运行中的会话仍轻缓落沙。

## 0.4.2

全局显示使用固定的跨桌面窗口，关闭系统额外显隐动画。仅 Codex 显示时，离开 Codex 或切换桌面立即隐藏；返回时还需确认当前桌面存在 Codex 窗口，避免旧前台状态造成反复显隐。桌面切换后的短暂稳定等待仅影响重新显示，不延迟隐藏。
